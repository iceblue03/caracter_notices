# works.json 채우기 가이드 (하위 모델용)

`src/works.json`은 분류기의 **원본 데이터**입니다. 각 작품(work)에 대해
`aliases`(작품명 별칭)와 `characters`(대표 캐릭터 2~3명)를 채우는 것이 목표입니다.

## 스키마

```jsonc
{
  "id": "w001",            // ⚠️ 절대 수정/재정렬 금지
  "title": "원피스",        // ⚠️ 절대 수정 금지 (사용자가 준 라벨)
  "category": "애니메이션",  // ⚠️ 수정 금지 ("애니메이션" | "게임")
  "aliases": [],           // ✅ 채우기: 작품명 별칭 (한/영/일 + 약칭)
  "characters": []         // ✅ 채우기: 대표 캐릭터 2~3명
}
```

캐릭터 항목 형식:

```jsonc
{ "name": "몽키 D. 루피", "aliases": ["루피", "luffy", "몽키디루피", "ルフィ"] }
```

## 규칙

1. **`id`, `title`, `category`는 절대 건드리지 않는다.** 순서도 그대로.
2. `aliases`에는 그 작품을 가리키는 **검색용 표기**를 넣는다:
   - 한국어 정식 명칭 + 흔한 약칭 (예: `귀칼` → `["귀멸의 칼날", "귀칼", "kimetsu no yaiba", "demon slayer", "鬼滅の刃"]`)
   - 영문 표기, 일본어 원제(있으면)
   - 이미 `title`에 있는 문자열도 포함해도 됨(중복은 자동 제거됨).
3. `characters`는 그 작품의 **대표 캐릭터 2~3명**. 각 캐릭터의 `aliases`에는
   한/영/일 이름과 흔한 약칭을 넣는다. (매칭은 이 별칭들로 이뤄짐)
4. 별칭은 **2글자 이상**을 권장 (1글자는 매칭에서 무시됨). 너무 흔한 일반 단어
   (예: "파워", "지")는 오탐이 생길 수 있으니 가능하면 구체적 표기를 우선.
5. `title`이 약칭이라 어떤 작품인지 모호하면, 가장 널리 알려진 해석으로 채운다.

## 이미 채워진 예시 (템플릿)

`w001 원피스`, `w031 체인소맨`, `w071 주술회전` 세 개는 예시로 채워져 있습니다.
같은 형식으로 나머지를 채우면 됩니다.

## 채운 뒤

- 앱은 `works.json`을 자동으로 읽어 각 작품을 구독/매칭 단위로 반영합니다.
  (별도 코드 수정 불필요)
- `aliases`/`characters`가 비어 있어도 `title`(작품명)로는 매칭되므로,
  부분적으로 채워도 동작합니다.
